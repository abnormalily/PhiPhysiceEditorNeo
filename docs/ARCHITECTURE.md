# 架构说明

## 分层

```text
main.cpp
  └─ ui::beginFrame / App::update / App::draw
       ├─ App（app/App.cpp）
       │    ├─ NoteLibrary（model/NoteType.cpp）
       │    ├─ Document（model/Document.cpp）
       │    ├─ World（physics/Physics.cpp）
       │    ├─ ProjectIO（io/ProjectIO.cpp）
       │    └─ Settings（app/Settings.cpp）
       └─ editorui::draw（ui/Editor*.cpp）
            ├─ Theme / Layout / Ui（自绘控件）
            ├─ Canvas / Inspector / Library / Project 面板
            ├─ ShapeEditor / ProjectDialog / Settings
            └─ Toasts
```

设计坐标采用 **Y-up**（向上为正），屏幕投影时统一翻转 Y；物理世界的重力为 `{0, -g}`，旧工程/旧音符文件在载入时迁移。

界面使用固定的 1600×900（16:9）虚拟画布，并通过 2D 相机直接映射到窗口的原生帧缓冲，因此窗口缩放和 Windows 高 DPI 下文字、线条仍然清晰。默认窗口为 1600×900，画布缩放为 50%。窗口启用 4× MSAA；高 DPI 帧缓冲下的裁剪矩形按真实像素高度计算。默认关闭垂直同步，由 60 FPS 目标帧率控制刷新。放大时字体图集会按档位重新生成；鼠标坐标先按 `GetWindowScaleDPI()` 换算到帧缓冲像素，再与绘制使用同一套缩放/偏移反变换到虚拟坐标。所有控件是自绘的 immediate-mode 控件（按钮、开关、数值输入框、文本框、分段选择、滚动区域、图标）。数值输入框接受点击后键入文本；文本框支持按住 `Backspace` 连续删除。

主题保存在 `theme::` 的语义色变量中，`theme::setLightMode()` 与 `theme::setAccentColor()` 在运行时重建强调色，绘制代码每帧读取当前颜色。八种马卡龙主题色（含灰色）以沿 45° 直径分成深色 / 浅色两半的圆形按钮呈现，设置窗口分为基础 / 外观 / 快捷键三页。日间/夜间模式、主题色、全部显示开关、场景参数、缓步挡位、全局铆钉半径和自定义快捷键保存在 `settings.ini`，由 `app/Settings.cpp` 读写；启动时先载入设置再创建界面。程序图标由 `tools/generate_icon.py` 生成 `assets/icon.png`（窗口图标）和 `src/app/app.ico`（Windows 可执行文件资源）。

画布上的多边形在 Y-up 设计空间中三角化后再投影到屏幕；Y 翻转会反转绕序，因此填充三角形按屏幕空间顺时针提交。音符填充使用完全不透明的类型颜色，选中状态只用轮廓光晕和选择框表示。暂停时只压暗背景（网格、场景框），音符、判定线与力场保持原色，状态提示绘制在遮罩之上。

## 文档与模拟世界

`Document` 是唯一的编辑数据源，保存坐标与关节的**局部锚点**。`App::rebuildWorld()` 根据文档重建一个 `World`：

- 每个音符按类型文件重新三角化（合并类型默认变量、该音符的变量覆盖值，再求值 `$节点` 坐标覆盖），密度/摩擦/弹性取自类型；
- 每个音符的 `GravityDirection` 转成单位方向，物理世界用场景重力的模长乘以该方向；`None` 对应零向量；
- 每条判定线是静态盒体（默认 4000 × 5 px）；它由“原件库 → 场景块”选中后按放置键（默认 `2`）放置，可在画布上拖动，或通过检查器修改角度、尺寸与颜色；判定线放置预览直接使用当前尺寸/角度，因此长宽改变会立即反映在预览中；
- 物理块与场景块分别从 `components/physics` 和 `components/scene` 加载同名 `.note` 文件；场景块使用自己的文件，但 `Note::scene` 仍会生成固定在世界中的静态刚体，只参与碰撞（Hold 也不例外）；
- 每个力场转换成 `World::forceFields` 中的世界固定体积：引力场向中心、斥力场向外施加与到中心距离成反比的加速度（中心最大），浮力场按阿基米德公式产生真实浮力，阻力场按系数衰减动量，引力改变场改写进入音符的重力方向，涡流场施加绕中心旋转的切向加速度（正数顺时针、负数逆时针）；默认情况下只有中心进入体积的动态音符会受影响；
- 音符文件中的 (0,0) 是对象原点，变量/节点绑定只移动顶点、不移动原点；构建物理刚体时再单独把轮廓平移到面积质心，因此原点与重心相互独立。Hold 的原点在底部，加高只抬升 0 / 5 / 6 / 7 节点和重心；
- 浮力不是额外动力或采样点近似：每个动态刚体的凸块与力场体积做裁剪，累加实际排水面积并求排水区域形心，再用 `F = 流体密度 × 排水面积 × 重力` 在形心施加冲量，因此部分覆盖会自然产生升力和转矩，方向始终与重力相反；
- 场景显示框（1350 × 900）只是绘制内容，不进入文档、也不是刚体；
- 铆钉是独立原件（预留类型 `Rivet`，不再作为音符附属显示）：物理版是受重力但不参与碰撞的动态刚体，场景版是静态刚体；半径由原件库底部的全局设置统一控制，颜色仍可按实例保存。两者都可与音符/其他铆钉建立铰链。铰链把文档中的局部锚点转成米制并绑定到刚体，连接到铆钉时物理销轴取铆钉中心，否则取两个显示端点的中点；移动物件后重建世界即可自动修复位置；
- 被非碰撞关节连接的音符合并到负碰撞 group；
- 模拟过程中 `Body` 的位置/角度变化不回写文档，直到用户拖动/旋转（编辑前会重置到布局）或保存布局。

这种“文档 = 初始布局，World = 当前模拟”的分离让“重置”和“保存工程”语义清晰。

## 物理引擎（physics/Physics.cpp）

1. **质量属性**：用三角形面积、质心、关于原点的转动惯量累加；App 在构建刚体前把轮廓平移到面积质心，因此物理身体原点就是重心，而文档中的音符原点（Hold 为底部中心）保持不变。
2. **宽相**：AABB 扫掠排序。
3. **窄相**：凸形音符用完整轮廓做 SAT；凹形音符用凸块对做 SAT。选取穿透最小的参考边，裁剪入射边，生成最多两个接触点。凹形的内部三角边接触会按真实轮廓距离剔除，并按接触位置去重；接触点转成局部锚点用于稳定求解。
4. **求解**：
   - 重力/阻尼积分；
   - 速度求解：法向（含 Baumgarte 偏置 + 弹性偏置）和库仑摩擦，累积冲量并热启动；
   - 位置积分；
   - 位置修正：沿法向用有效质量修正穿透；
   - 关节用点约束的 2×2 有效质量矩阵求解（焊接为两个点约束）；
   - 休眠：低线速度/角速度持续 0.75s 后睡眠，接触或外力唤醒。
5. **碰撞过滤**：category/mask 与负 group；静态判定线不参与动态积分。
6. **重力**：`World::gravity` 提供方向与模长；动态刚体可通过 `gravityDirection` 覆盖方向。
7. **力场**：`World::forceFields` 在每次 `step` 的重力积分之后向进入体积的动态刚体施加加速度，并唤醒被力场作用的睡眠刚体。引力场可选阻尼按系数衰减线速度/角速度；阻力场只衰减动量；引力改变场把该步已施加的重力替换为箭头方向（大小仍取场景重力）；涡流场按到中心的切向方向施加有符号加速度，正数顺时针、负数逆时针。浮力场把刚体凸块裁剪到力场体积内，按排水面积和形心施加阿基米德浮力，不再使用底部阻力或逐点动力模拟。
8. **缓步模拟**：`World::slowMotionGear` 为 0 时正常单步；为 5–50 时每个 `step` 拆成对应数量的子步。挡位由设置页的滑动杆控制并写入 `settings.ini`，工程文件也保留一份用于兼容。

## 变量与表达式

`NoteType` 保存变量定义（名称/显示名/默认值）和节点绑定（顶点索引 + X/Y 表达式）；`Note` 保存该实例的变量覆盖值。表达式由 `model/NoteType.cpp` 中的递归下降解析器求值，支持变量、常量、四则运算、幂、括号和常用函数。形状编辑器的“变量 / 节点”页编辑类型定义，保存时写回 `.note`；选中音符的检查器编辑实例值并写入工程的 `[notevars]`。渲染、物理和检查器共用 `NoteType::renderVertices(values)`，因此画布、模拟和输入框始终一致。

## 字体图集

界面不再依赖少量预烘焙汉字。`ui::loadFont` 用 `std::ifstream` 读取 `.ttf` 字节，绘制字符串时按需用 `LoadFontData` 栅格化每个码点，再写入 1024 × 1024 的 RGBA 图集页；只有实际绘制过的字符占用显存，因此字体文件中的大部分中文字符（包括 `.note` 变量显示名里的生僻字）都能显示。

图集按小 / 中 / 大三档绘制字号选择，基准栅格分辨率是旧版 16/28/42 px 的两倍（32/56/84 px）；窗口放大时只做小幅档位增长，避免把超大字形的细笔画缩没。字宽、行高、加粗重绘全部走同一套动态字形缓存。字体来自 `assets/fonts/PhiPhysiceNeoSans-Regular.ttf`，增加中文文案无需重新生成字形表。

字体字节同样通过内存读取，不把中文路径直接传给 raylib 的文件加载函数，因此工程放在中文目录也能正常显示。
