# PhiPhysiceEditorNeo

PhiPhysiceEditorNeo 是一个自包含的 2D **多边形物理音符编辑器**。

项目使用 C++20、raylib 和自研物理引擎构建，项目由DeepSeek Harness对abnormalily制作的PhiNote物理模拟器进行项目重构。
