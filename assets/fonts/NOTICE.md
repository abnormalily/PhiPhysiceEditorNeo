# 界面字体说明

## 文件

- `PhiPhysiceNeoSans-Regular.ttf`（约 10.1 MB）

## 来源与修改

- 原始字体：**Noto Sans SC** 2.004 可变字体（`wght` 100–900），来自
  [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc)。
- 原始版权：`Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.`
- 本项目的处理：只取 `wght=400`（Regular）静态实例，并把字体族名改为
  **PhiPhysice Neo Sans**；字形轮廓没有重新设计。这样做同时满足 SIL OFL 1.1
  对衍生字体的要求，并避免使用原字体的保留名称。
- 本字体是 SIL OFL 1.1 的“修改版本”（Modified Version），同样按 OFL 1.1
  分发，不单独出售；完整许可文本见同目录的 `LICENSE-OFL.txt`。

## 为什么不再直接使用 Noto 文件名

原项目中的文件名为 `NotoSansSC-Regular.ttf`，但文件本身是默认字重 100（Thin）
的可变字体。直接分发既容易让用户误以为它是 Regular，也不方便说明衍生关系。
1.0 版本改为静态 Regular 实例并重命名字体族，界面文字更清晰，授权信息也更完整。
